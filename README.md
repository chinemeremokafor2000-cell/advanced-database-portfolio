
 Project Overview

This repository contains the practical work for an individual Advanced Database Systems portfolio based on a simulated digital banking system, NovaBank. The project demonstrates relational database design, query optimisation, transaction management, NoSQL data modelling and distributed cloud database concepts.

Portfolio Structure

1. **Portfolio 1 – Database Design and Modelling:** PostgreSQL schema, seven related tables, ER diagram, constraints and normalisation.
2. **Portfolio 2 – Query Processing and Optimisation:** SQL queries, indexing, execution plans and performance comparison.
3. **Portfolio 3 – Transactions and Concurrency:** Commit, rollback, savepoints and concurrent transaction testing.
4. **Portfolio 4 – NoSQL and Advanced Data Models:** MongoDB collections, embedded documents, queries and aggregation.
5. **Portfolio 5 – Distributed and Cloud Database:** MongoDB Atlas replica-set deployment and architecture documentation.

### Technologies Used

- PostgreSQL 18.6 and pgAdmin 4
- MongoDB Atlas
- Visual Studio Code
- Git and GitHub

Each portfolio folder contains its relevant implementation files, individual README documentation and supporting evidence.
