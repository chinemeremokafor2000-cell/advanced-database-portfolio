## 1. Project Overview

This repository contains the practical implementation of an individual Advanced Database Systems portfolio based on a simulated digital banking system, NovaBank.

The project demonstrates the application of relational database design, query processing and optimisation, transaction management, NoSQL data modelling, and distributed cloud database concepts within a banking environment.

NovaBank's simulated operations include customer registration, account management, card management, beneficiary management, deposits, withdrawals and fund transfers.
